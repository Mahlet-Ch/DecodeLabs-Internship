# Rule-Based AI Chatbot

## Project Overview

This project is a simple **Rule-Based AI Chatbot** developed using Python. The chatbot interacts with users by responding to predefined questions and commands using `if`, `elif`, and `else` statements. It demonstrates basic Artificial Intelligence concepts through rule-based decision making.

## Features

- Greets users and remembers their name.
- Responds to common greetings.
- Answers basic questions about:
  - Artificial Intelligence (AI)
  - Python
  - HTML
  - CSS
  - JavaScript
  - Machine Learning
  - Programming
  - Git
  - GitHub

- Provides a **Help** menu showing available commands.
- Tells a programming joke.
- Shares a fun fact.
- Responds to simple user emotions (happy, sad, fine).
- Handles unknown questions with a friendly message.
- Allows users to exit the chatbot by typing **bye**.

## Technologies Used

- Python 3

## Concepts Used

- Variables
- User Input (`input()`)
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`)
- String Methods (`lower()`)
- Rule-Based Logic

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run the program:

```bash
python chatbot.py
```
