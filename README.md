# DecodeLabs AI Internship Projects

Welcome to my DecodeLabs AI Internship repository! This repository contains the projects I completed during my internship to practice Python programming, problem-solving, and basic AI concepts.

## Projects

### 📁 Project 1: Rule-Based AI Chatbot

A simple chatbot built with Python that responds to predefined user questions using rule-based logic.

**Features:**

- Greets users and remembers their name.
- Answers common questions about AI, Python, HTML, CSS, JavaScript, Git, and GitHub.
- Includes a help menu.
- Tells jokes and fun facts.
- Allows users to exit the chat anytime.

**Technologies Used:**

- Python

---

### 📁 Project 2: AI Classification

A simple rule-based classification system that classifies student results based on predefined conditions.

**Features:**

- Reads student data.
- Applies classification logic.
- Displays the classification results.

**Technologies Used:**

- Python
- Pandas

---

### 📁 Project 3: AI Food Recommendation System

A rule-based recommendation system that suggests meals based on the user's preferences.

**Features:**

- Recommends meals based on meal type, food preference, and budget.
- Allows users to get another recommendation.
- Includes options to return to previous menus or exit the program.
- Handles invalid input.

**Technologies Used:**

- Python
