# 🍽️ AI Food Recommendation System

## About the Project

This is a simple **AI Food Recommendation System** built with Python. The program asks users a few questions about what they want to eat, such as the meal time, food preference, and budget. Based on their answers, it recommends a meal using rule-based logic.

The goal of this project is to practice Python programming and understand the basic idea of how recommendation systems work.

## Features

- Recommends meals based on user preferences.
- Lets users choose:
  - Breakfast, Lunch, Dinner, or Snack
  - Vegetarian or Non-Vegetarian
  - Low, Medium, or High budget

- Allows users to get another recommendation without restarting the program.
- Includes options to return to previous menus or exit the application.
- Handles invalid input with simple error messages.

## Technologies Used

- Python 3

## Concepts Used

- User input
- Variables
- `if`, `elif`, and `else` statements
- Nested conditions
- `while` loops
- Rule-based decision making

## How to Run

1. Download or clone this project.
2. Open the project folder in your terminal or command prompt.
3. Run the following command:

```bash
python food_recommendation.py
```
